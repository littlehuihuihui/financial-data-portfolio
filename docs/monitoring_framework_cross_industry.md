## 1. 五层对照

| 层级 | 零售财务 | 互联网 OTT | 制造业 |
|------|----------|------------|--------|
| **北极星** | 净利率 | 有效 MAU | CMEI（FPY×40%+OEE×35%+OTD×25%） |
| **围栏** | 退货率、净现比、库存周转天数 | D7 留存、完播率、LTV/CAC | 良品率/FPY、单位成本、来料 PPM |
| **核心** | 净收入、毛利率、费用率、ROE | DAU、留存、ARPU/订购、漏斗转化 | 产量、FPY、OEE、OTD |
| **先导** | 客单价、退货率、ROAS、周转 | 新增、只开机占比、CAC、使用深度 | WIP、故障/停机、来料不良、换型 |
| **诊断** | 品牌/渠道/品类毛利与退货、门店坪效等 | 端型/渠道/内容/漏斗/健康度 | 产线良率、不良柏拉图、OEE 三因子、供应评分等 |
| **警戒线** | 毛利率同比↓>2pp；退货>15% 等 | 留存环比↓>5pp；LTV/CAC<1 等 | 良品率<95%/92%；OEE<75% 等 |

## 2. 与原有两套结构的关系

| 结构 | 用途 | 是否替代监控五层 |
|------|------|------------------|
| 受众四层（战略/经营/业务/现场） | 谁看、多久看 | 否，互补 |
| 分析六层（描述→…→工具箱） | 怎么分析问题 | 否，互补 |
| **监控五层（本文）** | 盯什么、何时预警、何为围栏 | — |

## 3. 缺失补充总清单（跨行业优先级）

| 优先级 | 项 | 行业 | 动作 |
|--------|----|------|------|
| P0 | 总览标明北极星/围栏 | 全 | ✅ KPI `role` 标签 + 页头图例 |
| P0 | 制造总览露出 CMEI | 制造 | ✅ 有数据则展示北极星卡 |
| P1 | 零售总览增加净利率 KPI | 零售 | API/`v_overview` 微调 |
| P1 | 互联总览增加围栏摘要（D7 或 LTV/CAC） | 互联 | 总览加 1 张迷你 KPI |
| P1 | 警戒线配置化（黄/红） | 全 | JSON/阈值，复用制造 alert_level、互联健康度 |
| P2 | 先导/围栏弱指标补字段 | 制造来料 PPM、零售新品占比 | DWS 字段 |
| P3 | 独立告警中心 | 全 | 非必须 |
