多行业平台 · PyCharm 傻瓜步骤
================================

【最简单 · 不用 PyCharm】
双击：portfolio\一键启动.bat
浏览器打开：http://127.0.0.1:5100/


【用 PyCharm · 已写好配置，不用自己选 3.8/3.9】

1. 用 PyCharm 打开文件夹：
   d:\cursor\财务数据分析\retail-finance-analysis

2. 看右上角运行配置下拉框，应出现：
   - Retail API          （零售看板数据，端口 5000）
   - Portfolio Platform  （多行业入口，端口 5100）

3. 先选 Retail API → 点绿色三角运行
   看到 Running on http://127.0.0.1:5000 即成功

4. 再选 Portfolio Platform → 点绿色三角运行
   看到 Running on http://127.0.0.1:5100 即成功

5. 浏览器打开：http://127.0.0.1:5100/
   点击「零售财务」卡片进入看板


【如果右上角没有这两个配置】

Retail API：
  Script:     retail-finance-analysis\app.py
  工作目录:   retail-finance-analysis
  解释器:     Python 3.9 (retail-finance-analysis)  ← 带项目名那个

Portfolio Platform：
  Script:     portfolio\portfolio_app.py
  工作目录:   portfolio
  解释器:     选手动添加 → portfolio\venv\Scripts\python.exe


【Python 3.8 / 3.9 怎么选？】
不用管系统里的 Python 3.8、3.9。
选带 venv 路径的那个，或上面两个已配好的运行配置。
