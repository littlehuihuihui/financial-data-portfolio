多行业平台 · PyCharm 怎么打开 / 运行
====================================

【最简单】
双击：portfolio\一键启动.bat
浏览器：http://127.0.0.1:5100/


【PyCharm · 推荐】

1. File → Open → D:\cursor\多行业数据平台
2. 右上角运行配置只保留这 5 个：
   - All Services (5000+5001+5002+5100)  ← 一次全开
   - Portfolio Platform 5100
   - Retail API 5000
   - Internet API 5001
   - Manufacturing API 5002

3. 选「All Services」→ Run
4. 浏览器：http://127.0.0.1:5100/

解释器：
  Retail → retail-finance-analysis\venv\Scripts\python.exe
  其余 → portfolio\venv\Scripts\python.exe


【前端唯一目录】
  portfolio/industries/{retail|internet|manufacturing}/
  retail-finance-analysis/docs/ 已删除


【不要】
- 不要用旧配置名：app / 启动全部 / Portfolio Platform（无端口号）
- 不要只开 :5000 当作品集入口（UI 用 :5100）
