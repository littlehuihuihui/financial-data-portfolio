# 工程专题 E6 · CDC 与增量：概念对齐作品集

## 1. 批式 vs CDC

| | 天批 / 微批 | CDC |
|--|-------------|-----|
| 触发 | 时间调度 | 日志/变更流 |
| 典型 | 日分区重算或增量 SQL | Binlog → 入仓 |
| 延迟 | 小时～天 | 秒～分钟级 |

## 2. 本作品集是什么

> **证据**：`seed_ott.py` 为脚本重建/灌数；ETL 面板多 `python`/`view`；零售另有 `etl_daily_schedule.py` 等**演示向**调度说明。  

**没有**完整生产级 CDC 管线实现。学习时：用 CDC 概念做方案对比题，不要声称仓库已上线 Debezium。

## 3. 何时该上 CDC（决策题）

- 业务要日内新鲜度  
- 全量抽代价过高  
- 需近似实时维表  

代价：一致性、乱序、回放、运维复杂度。
