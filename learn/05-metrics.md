# 第 05 章 · 指标口径工程与看板消费

## 1. 本章目标

1. 建立「指标」作为产品：定义、计算、责任人、变更流程。  
2. 掌握口径四件套，并能落到 DWS/ADS 字段。  
3. 理解看板只是消费层：稳定来自口径与汇总，不来自图表库。  
4. 会设计北极星与护栏指标，避免「唯一下钻一个数」。

---

## 2. 理论：什么是合格的指标定义

一个可上线的指标至少包含：

| 字段 | 含义 |
|------|------|
| 业务含义 | 老板听得懂的一句话 |
| 技术口径 | 精确到表.字段与过滤条件 |
| 来源表 | 优先 DWS/ADS |
| 刷新频率 | T+1 / 日内 / 实时视图 |
| 排除规则 | 测试、内部、退订、未支付… |
| 负责人 | 业务 owner + 数据 owner |
| 关联看板 | 哪些页面消费它 |

没有排除规则的「收入」「活跃」，必然吵架。

---

## 3. 口径分层：原子指标 vs 派生指标

- **原子指标**：可加度量，如订单金额、有效播放次数——适合进 DWS  
- **派生指标**：比率、占比、转化率——适合 ADS 用原子指标计算  
- **衍生业务指标**：北极星综合分——可在 ADS 或应用层加权  

错误：把转化率写入 DWD 再 SUM。

---

## 4. 看板消费链

```
指标字典 → DWS/ADS 字段 → API/数据集 → 图表组件 → 经营动作
```

设计看板时的纪律：

1. 一张图对应明确指标 ID  
2. 时间宏、维度切片与口径一致  
3. 异常下钻路径预先设计（到哪张明细）  

互联网作品集还有 **北极星阶段**：不同阶段强调不同主指标，但底层表可共用——这是「经营策略」而非「改数仓」。

---

## 5. 变更管理（实用）

口径变更必须：

1. 评估影响看板与下游  
2. 决定是否回刷历史  
3. 发版说明（旧口径保留多久）  
4. 回归用例（固定日期切片对比）
