# 互联网（OTT）· 数据监控指标体系

> 五层监控：北极星 → 核心 → 先导 → 诊断 → 警戒线  
> 与看板 / 数仓对齐；**不新增主题看板**。  
> 状态：文档 v1.0 · 对齐作品集 internet v2.8

## 0. 角色定义（本页必读）

| 标签 | 含义 | 本行业选定 |
|------|------|------------|
| **北极星** | 唯一主优化目标 | **有效 MAU**（STB+Speaker；有实质播放/交互的月活，非裸开机） |
| **围栏指标** | 冲北极星时不能恶化的底线 | **D7 留存**、**完播率（点播）**、**LTV/CAC** |
| 核心指标 | 周/月必看 | DAU、留存、ARPU/订购、收银台转化 |
| 先导指标 | 更早预判 | 新增激活、只开机占比、CAC、功能使用率（点播/直播） |
| 诊断指标 | 异常下钻 | 端型/渠道/版本 DAU、渠道留存、题材完播、漏斗步骤转化 |
| 警戒线 | 阈值规则 | 见 §2 |

**说明：** LTV/CAC 是商业健康**围栏**，不是本作品集北极星；冲有效 MAU 时若 LTV/CAC<1 视为围栏击穿。

## 1. 五层指标拆解表

### 1.1 北极星（1）

| 指标 | 计算逻辑 | 数据来源 | 关键字段 | 状态 |

### 1.2 核心指标（4）

| 指标 | 计算逻辑 | 数据来源 | 状态 |
|------|----------|----------|------|
| DAU | 日去重活跃设备 | `dws_act_user_active_1d` | 已有 · 活跃总览 |

| 收银台转化率 | 漏斗末步÷曝光 | `dws_trade_cashier_funnel_1d` | 已有 · 漏斗看板 |

### 1.3 先导指标（4）

| 指标 | 计算逻辑 | 数据来源 | 状态 |
|------|----------|----------|------|
| 新增/激活设备 | 新 MAC 或首活 | 活跃/生命周期 DWS | 已有 |
| 只开机占比 | 仅 Launcher 无点播直播 | 开机看板 ADS | 已有 · 质量先导（升高=虚胖） |

| 指标 | 下钻维 | 看板 | 状态 |
|------|--------|------|------|
| 端型有效 MAU/DAU | STB / Speaker | 活跃总览、设备 | 已有 |
| 入口/渠道留存 | launcher / video 等 | 留存、渠道 | 已有 |
| 题材/剧集完播 | 内容维 | 剧集/单集 | 已有 |
| 漏斗步骤转化 | 曝光→…→支付 | 漏斗 | 已有 |
| LTV/CAC | 入口维 | LTV、渠道评分 | 已有 · **兼围栏** |
| 只开机分端 | 端型 | 开机 | 已有 |
| QoS / 卡顿 | 体验代理 | QoS | 已有 |

### 1.5 围栏指标

| 围栏 | 为何 | 底线含义 |
|------|------|----------|
| D7 留存 | 刷新增可抬 MAU，留不住则虚 | 留存掉而 MAU 升 → 击穿 |
| 点播完播率 | 内容体验底线 | 完播崩而 VV 升 → 击穿 |
| LTV/CAC | 单位经济 | <1 时禁止加投冲 MAU |

## 2. 警戒线规则表

| 指标 | 正常 | 关注 | 异常 | 依据 |
|------|------|------|------|------|
| 有效 MAU | 环比 ≥ -2% | 环比 ↓2–5% | 环比 ↓>5% | 环比 |
| DAU | 同比/环比平稳 | 环比 ↓3–8% | 环比 ↓>8% | 环比 |
| D7 留存（围栏） | ≥ 基线 | 环比 ↓2–5pp | 环比 ↓>5pp | 环比 |
| 完播率（围栏） | ≥ 题材基线 | ↓3–5pp | ↓>5pp 或连续 2 周 | 环比 |
| LTV/CAC（围栏） | ≥2 | 1–2 | <1 | 绝对值 |
| CAC | 环比 ≤+10% | +10–20% | +>20% | 环比 |
| 只开机占比 | ≤ 历史中位 | 升 3–5pp | 升 >5pp | 环比 |
| 收银台转化 | ≥ 基线 | ↓10–20% 相对 | ↓>20% 相对 | 环比 |
