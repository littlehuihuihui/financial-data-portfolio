3. KPI 卡片制作技巧

  • 计算字段 同比变化率 = (当期值 − 去年同期值) / 去年同期值
  • 计算字段 环比变化率 = (当期值 − 上期值) / 上期值
  • Unicode 箭头：↑ (U+2191)、↓ (U+2193)
  • 条件格式：正增长 #27ae60，负增长 #e74c3c

4. 环形图制作技巧

  • 创建两个饼图叠加（双轴）
  • 底层饼图只留一个标记，设置为白色
  • 上层饼图显示渠道占比：渠道 → 颜色，净收入 → 角度

折线图 · 快速对照

订单月份拖到列，净收入拖到行，标记选「折线图」· X 轴连续月份 (YYYY-MM) · Y 轴净收入金额

📐 财务数据分析方法论

六层分析框架 · 遇到业务问题先判断层级，再按对应方法展开

描述（现状）→ 诊断（根因）→ 预测（未来）→ 评估（效果）→ 优化（决策）

📋 体系总览 📊 经营监控看板 📐 分析方法论 ⚙️ 数仓架构

1 描述性分析 — 「现在是什么状况？」

目的：客观描述现状 · 方法：KPI → 趋势 → 结构 → 排名

数据：dws_sales_monthly（按月汇总）、dws_sales_daily、dws_store_daily

看板：经营总览 · 品牌 · 渠道 · 门店

↓

2 诊断性分析 — 「为什么会这样？」

目的：根因定位 · 路径：品牌→渠道→品类→SKU · 产出：根因+影响金额

数据：dws_sales_daily、dwd_sales_wide、ods_orders（return_flag=1）

案例：Life 毛利率 52%→48%（抖音鞋类折扣 25%→42%，-1,400万）· 抖音退货 15%→22% · ROAS 3.0→2.1

↓

3 预测性分析 — 「接下来会怎样？」

方法：趋势外推 / 移动平均 / 指数平滑 · 产出：乐观/基准/悲观三情景

示例：Q3 收入预测 2.5–2.9 亿（基准 2.7 亿）· 看板：现金流分析

↓

4 评估性分析 — 「做得怎么样？」

方法：ROI/ROAS · vs 目标/历史/行业 · 示例：天猫 ROI=3.5（行业 2.8）优秀，建议加投

↓

5 优化性分析 — 「应该怎么做？」

方法：边际分析 · 敏感性 · What-if · 示例：抖音减投 100 万挪天猫，利润 +180 万

看板：预算执行 · 本量利分析

  • 利润 → 权益：权益变动 ≈ 净利润（分红/增资除外）
  • 利润 → 现金流：经营现金流 = 净利润 + 非现金支出 − 营运资本变动
  • 资产 = 负债 + 权益：dws_asset_monthly 恒等式（权益为残差）

分层是什么？

ODS · 操作数据层
原始数据落地，与 CSV / 业务表一一对应（*_raw 视图），不做复杂加工。
DWD · 明细数据层
清洗后的明细事实 + 维度表（dwd_sales_wide、dim_*），星型模型。
DWS · 汇总数据层
按日 / 月等粒度预聚合（dws_sales_daily 等），供看板快速查询。
ADS · 应用数据层
面向 Tableau / Web 的业务视图，封装指标口径，直接给前端用。

口诀：ODS 存原始 → DWD 洗干净 → DWS 先算好 → ADS 给业务用。

维度建模关系

核心事实表 dwd_sales_wide 通过外键关联 4 张维度表，构成星型模型：

  • date_id → dim_date（时间维度，支持下钻年 / 季 / 月 / 日）
  • brand_id → dim_brand（品牌：跃动Pro / Life / Go）
  • channel_id → dim_channel（渠道：抖音 / 天猫 / 线下直营 / 其他）
  • category_id → dim_category（品类：鞋类 / 服装 / 配件）

血缘应用：问题溯源与变更影响

问题溯源（自下而上）：看板指标异常时，从 ADS 视图定位月份/维度 → 下钻 DWS 汇总表 → 回查 dwd_sales_wide 订单明细 → 对比 ODS 原始数据，逐层锁定是口径、清洗还是源数据问题。

变更影响（自上而下）：修改 ETL 规则或指标公式前，查血缘表「下游依赖」列评估影响面（如改渠道映射会影响 dwd_sales_wide 及全部销售类 ADS）；变更后按 ODS→DWD→DWS→ADS 重跑 ETL 并对账。
