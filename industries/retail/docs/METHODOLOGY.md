# 零售财务行业 · 数据分析方法论（完整版）

与互联网、制造业框架统一，面向零售/电商/品牌财务分析场景，严格遵循管理会计与财务分析标准。

**业务主线：** 商品采购 → 库存管理 → 渠道销售 → 财务核算 → 经营分析  
**核心目标：** 提收入、控成本、降库存、增利润、控风险  
**北极星指标：** 净利润率、ROE净资产收益率、经营现金流

---

## 第一层 · 描述性分析（What happened? 发生了什么）

> 回答：经营情况怎么样？核心财务指标是多少？和预算/同期比差多少？

| 分析场景 | 核心指标 | 关联看板 |
|---------|---------|---------|
| 经营总览 | 收入、毛利、净利润、毛利率、净利率、费用率 | 经营总览看板 |
| 销售分析 | 各渠道/品牌/门店收入、销量、客单价、同店增长 | 品牌/渠道/门店看板 |
| 财务三表 | 资产负债表、利润表、现金流量表核心科目 | 财务看板 |
| 杜邦分析 | ROE拆解：净利率×资产周转率×权益乘数 | 杜邦分析看板 |
| 库存分析 | 库存金额、库存周转天数、库龄、滞销库存、动销率 | 库存看板 |
| 费用分析 | 销售/管理/财务费用、费用率、预算执行率 | 预算看板 |
| 现金流 | 经营/投资/筹资现金流、资金余额、现金周转期 | 现金流看板 |
| 税务分析 | 增值税、所得税、税负率、税务风险 | 税务看板 |
| 质量分析 | 数据质量、对账差异、异常指标 | 数据质量看板 |

## 第二层 · 诊断性分析（Why it happened? 为什么发生）

> 回答：指标异常的原因是什么？哪个产品/渠道/门店出了问题？

| 异常场景 | 下钻维度 | 诊断方法 |
|---------|---------|---------|
| 毛利率下降 | 渠道→品牌→品类→SKU→价格→成本→促销 | 因素分析法、量本利分析 |
| 净利润下滑 | 收入→成本→费用→税金→营业外收支 | 杜邦拆解、差异分析 |
| 库存周转慢 | 品类→SKU→库龄→门店→采购→销售 | 库龄分析、ABC分类 |
| 费用超预算 | 费用类型→部门→科目→时间→预算项 | 预算执行分析、费效比 |
| 现金流紧张 | 应收→应付→库存→回款周期→付款周期 | 现金转换周期分析 |
| 门店利润低 | 门店→坪效→人效→客单价→费用→租金 | 门店盈利分析、盈亏平衡 |
| 品牌增长慢 | 品牌→渠道→价格带→促销→竞品 | 品牌四象限分析 |
| 税务风险高 | 税负率→发票→进销项→关联交易→异常科目 | 税务风险指标预警 |

## 第三层 · 预测性分析（What will happen? 会发生什么）

> 回答：未来经营会怎么样？有没有风险？需要提前做什么？

| 预测场景 | 预测方法 | 业务价值 |
|---------|---------|---------|
| 销售预测 | 时间序列、季节因子、促销计划、历史趋势 | 采购计划、库存备货、人员安排 |
| 资金预测 | 应收应付账期、销售预测、费用预算 | 资金安排、融资计划、避免资金链断裂 |
| 库存预测 | 销售预测、提前期、安全库存模型 | 避免缺货、减少滞销库存、优化周转 |
| 利润预测 | 量本利模型、费用预算、价格策略 | 目标制定、经营决策、预算编制 |
| 费用预测 | 历史费用率、销售占比、固定/变动费用拆分 | 预算控制、费用审批 |
| 税务预测 | 业务预测、税收政策、优惠政策 | 税务筹划、合理避税、避免税务风险 |
| 应收坏账预测 | 账龄分析、客户信用、历史坏账率 | 坏账准备、催收策略、信用政策 |

## 第四层 · 处方性分析（What should we do? 应该怎么做）

> 回答：针对问题应该采取什么措施？不同方案对利润的影响是什么？

| 问题场景 | 优化方案 | 预期效果 |
|---------|---------|---------|
| 毛利率低 | 优化供应链降采购成本、调整价格结构、减少低毛利SKU、提升高毛利品类占比 | 毛利率提升2-5个点 |
| 库存高 | 滞销品清仓促销、优化采购批量、JIT补货、ABC分类管理 | 库存周转天数减少10-30天 |
| 费用高 | 优化投放渠道提升ROI、控制固定费用、变动费用和收入挂钩 | 费用率降低1-3个点 |
| 现金流差 | 收紧应收账期、延长应付账期、优化库存减少资金占用 | 现金周转期缩短5-15天 |
| 门店亏损 | 关闭亏损门店、优化坪效、调整租金、提升客单价 | 门店盈利提升 |
| 预算超支 | 费用审批控制、预算预警、超支审批流程、费效比考核 | 预算执行率偏差控制在5%内 |
| 税务风险 | 规范发票管理、合理税务筹划、定期税务自查、利用税收优惠 | 税负率合理、无税务稽查风险 |

## 第五层 · 根因分析（Root Cause 根本原因是什么）

> 回答：财务异常的根本原因是什么？是业务问题还是核算问题？

| 根因方法 | 适用场景 | 零售财务应用示例 |
|---------|---------|--------------|
| **因素分析法** | 利润/收入/成本差异分析 | 利润少了100万→拆：量差影响-60万，价差影响-30万，成本影响-10万→根因：销量没达标 |
| **杜邦分析法** | ROE/利润率拆解 | ROE从15%降到10%→拆：净利率降了→费用率升了→销售费用升了→投放ROI降了→根因：某渠道投放效率低 |
| **本量利CVP分析** | 盈亏平衡、定价决策 | 门店亏损→算：固定成本20万/月，边际贡献率20%→盈亏平衡点100万/月→现在只做80万→根因：客流不够没到盈亏线 |
| **账龄分析法** | 应收/库存问题 | 应收逾期高→拆账龄：1年以上占30%→拆客户：某客户占了逾期的60%→根因：该客户信用政策太松 |
| **5Why分析法** | 单一财务异常 | 为什么库存周转慢？→滞销品多→为什么滞销？→采购多了→为什么采购多？→销售预测高了→为什么预测高？→拍脑袋没看历史数据→根因：预测流程不规范 |
| **差异分析法** | 预算vs实际、同期对比 | 费用超了20%→拆：差旅超了→哪个部门？→销售部→为什么？→出差多了→为什么？→新开门店支持→根因：新开门店预算没考虑差旅 |
| **往来对账** | 数据差异、账实不符 | 库存账实差100万→盘点→A商品盘亏→为什么？→出库没登账→为什么？→系统流程漏洞→根因：出库流程需要补单审批 |

## 第六层 · 闭环优化（How to improve continuously? 如何持续优化）

> 回答：如何形成经营闭环，从财务数据到业务改善，持续提升盈利。

| 闭环环节 | 零售财务落地方法 |
|---------|--------------|
| **Plan 预算** | 年度预算编制、目标拆解到月/部门/门店、滚动预测调整 |
| **Do 执行** | 预算控制、费用审批、业务执行、财务核算、数据记录 |
| **Check 分析** | 月度经营分析会、预算vs实际差异分析、财务预警、问题定位 |
| **Act 改进** | 针对问题出改进措施、跟踪落地、效果验证、考核挂钩 |
| **财务闭环** | 业务发生→财务核算→报表出具→经营分析→发现问题→业务改进→业务发生，月度循环 |
| **内控体系** | 财务制度完善、审批流程、风险控制点、内部审计、定期复盘 |
| **数据闭环** | 业务系统→财务系统→数仓→报表→分析→决策→业务系统，数据质量持续监控 |

## 💰 零售财务专属分析工具箱

| 分析方法 | 核心思想 | 应用场景 |
|---------|---------|---------|
| **杜邦分析** | ROE=净利率×资产周转率×权益乘数，层层拆解 | 盈利能力分析、股东回报分析 |
| **本量利CVP** | 成本-销量-利润关系，固定/变动成本拆分 | 盈亏平衡、定价决策、利润敏感性 |
| **因素分析法** | 连环替代，拆分量差/价差/成本差等各因素影响 | 差异分析、预算执行、利润变动原因 |
| **ABC分类法** | 80/20法则，A类20%商品贡献80%销售额/利润 | 库存管理、商品管理、重点管理 |
| **RFM客户分层** | 最近消费/消费频率/消费金额，客户价值分层 | 会员运营、精准营销、复购提升 |
| **库存周转分析** | 周转天数=平均库存/销售成本×天数，库龄分析 | 库存优化、减少资金占用、滞销管理 |
| **现金转换周期** | 应收天数+库存天数-应付天数，资金占用时间 | 现金流管理、营运资金优化 |
| **同店增长SSSG** | 剔除新开店影响，老店同比增长 | 真实经营能力评估、门店成熟度分析 |
| **坪效/人效** | 每平米销售额、每人销售额，单位产出 | 门店效率、人员效率、租金合理性 |
| **费效比ROI** | 投入产出比，费用带来的收入/利润 | 营销投放评估、费用控制、预算分配 |
| **账龄分析** | 应收/应付/库龄按时间段分层 | 坏账风险、库存风险、往来款管理 |
| **预算控制** | 预算编制→执行→控制→分析→考核闭环 | 费用管理、目标管理、经营管控 |
| **税务筹划** | 利用税收政策合理节税，规避税务风险 | 税务优化、合规经营、降低税负 |
| **毛利分析** | 毛利=收入-成本，分渠道/品牌/品类/SKU | 盈利结构、商品优化、定价策略 |

## 🏗️ 数仓模型设计

### 数仓分层架构
```
ADS 应用层 → 14个财务看板视图（经营/杜邦/现金流/库存/预算/税务）
 ↑
DWS 汇总层 → 日/月汇总表（科目日汇总、门店日汇总、库存日汇总）
 ↑
DWD 明细层 → 事实表（凭证事实、销售事实、库存事实、费用事实）
 ↑
DIM 维度层 → 维度表（日期、科目、门店、商品、供应商、客户、部门）
 ↑
ODS 贴源层 → 原始数据（ERP/POS/OMS/WMS/HR/银行）
```

### 核心事实表
1. **dwd_voucher_fact**：财务凭证明细事实表（分录粒度）
2. **dwd_sales_fact**：销售明细事实表（订单/流水粒度）
3. **dwd_inventory_fact**：库存出入库事实表（出入库单粒度）
4. **dwd_expense_fact**：费用明细事实表（报销单粒度）
5. **dwd_payment_fact**：收付款事实表（银行流水粒度）

### 核心维度表
1. **dim_date**：日期维度
2. **dim_account**：会计科目维度（层级：一级→二级→三级→四级，4层）
3. **dim_store**：门店维度（层级：区域→分公司→门店，3层）
4. **dim_product**：商品维度（层级：大类→中类→小类→SKU，4层）
5. **dim_supplier**：供应商维度（层级：分类→供应商，2层）
6. **dim_customer**：客户维度（层级：等级→客户，2层）
7. **dim_department**：部门维度（层级：中心→部门→小组，3层）
8. **dim_company**：公司维度（多账套合并用）

### ER图关系（星型+雪花混合模型）

                    │  dim_date   │ 日期维度

│  dim_account     │────│dwd_voucher_fact │────│   dim_company    │
│ (科目4层雪花)    │    │                  │    │                  │
└──────────────────┘    └──────────────────┘    └──────────────────┘
                                  │
                    ┌─────────────┴─────────────┐

                    └───────────────────────────┘

## 🔗 数据血缘关系

### 核心指标血缘（净利润为例）
```
业务源：ERP凭证 + 销售流水 + 费用报销
    ↓
ODS层：ods_finance_voucher / ods_pos_trade / ods_expense_report
    ↓ 清洗、借贷平衡校验、科目映射
DWD层：dwd_voucher_fact（凭证明细事实表）
    ↓ 按科目+日期+部门汇总借贷发生额
DWS层：dws_account_daily / dws_account_monthly（科目日月汇总）
    ↓ 按利润表项目归集：收入-成本-费用-税金=净利润
ADS层：ads_income_statement（利润表视图）
    ↓
看板：经营总览看板 / 财务分析看板
```

### 核心指标血缘（库存周转天数为例）
```
业务源：WMS库存 + POS销售
    ↓
ODS层：ods_inventory / ods_pos_trade
    ↓ 清洗、库龄计算、负库存校验
DWD层：dwd_inventory_fact / dwd_sales_fact
    ↓ 按商品+门店+日期汇总库存余额、销售成本
DWS层：dws_inventory_daily（库存日汇总）
    ↓ 库存周转天数 = 平均库存余额 / 销售成本 × 天数
ADS层：ads_inventory_analysis（库存分析视图）
    ↓
看板：库存分析看板
```

### 数据血缘管理原则
1. **全链路可追溯**：每个财务指标都能追溯到原始凭证，满足审计要求
2. **口径一致性**：同一科目、同一指标在所有报表中口径必须完全一致
3. **对账校验**：每层数据必须和上层对账，差异率为0才能进入下一层
4. **审计留痕**：所有数据变更必须有记录，支持反查和审计
