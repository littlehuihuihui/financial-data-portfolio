# 零售财务 · 数据监控指标体系

> 五层监控：北极星 → 核心 → 先导 → 诊断 → 警戒线  
> 与看板 / 数仓对齐；**不新增主题看板**，在现有总览与专题板上标注角色。  
> 状态：文档 v1.0 · 对齐作品集 retail v3.12

## 0. 角色定义（本页必读）

| 标签 | 含义 | 本行业选定 |
|------|------|------------|
| **北极星** | 公司级唯一主优化目标（本框架收敛为 1 个） | **净利率**（与 ROE、经营现金流同属战略层；日常盯净利率，月度看 ROE/现金流） |
| **围栏指标** | 优化北极星时**不允许恶化**的底线指标 | **退货率**、**经营净现比**、**库存周转天数** |
| 核心指标 | 周/月必看，直接支撑北极星 | 净收入、毛利率、费用率、ROE |
| 先导指标 | 更早波动，预判核心/北极星 | 客单价、退货率（兼围栏）、广告 ROI、新品占比 |
| 诊断指标 | 异常时下钻定位 | 品牌/渠道/品类毛利率、渠道退货率、品类周转等 |
| 警戒线 | 正常 / 关注 / 异常阈值 | 见 §2 |

**围栏 ≠ 警戒线：** 围栏是「优化时不能踩穿的底线指标」；警戒线是「每个指标何时变黄/变红的数值规则」。

## 1. 五层指标拆解表

### 1.1 北极星（1）

| 指标 | 计算逻辑 | 数据来源 | 关键字段 | 状态 |

### 1.2 核心指标（4）

| 指标 | 计算逻辑 | 数据来源 | 关键字段 | 状态 |
|------|----------|----------|----------|------|
| 净收入 | 成交净额（扣退） | DWS `dws_sales_daily` / ADS `v_overview` | `net_revenue` | 已有 · 经营总览 KPI |

| ROE | 净利率×周转×杠杆 | ADS `v_dupont` | `roe_pct` 等 | 已有 · 杜邦看板 |

### 1.3 先导指标（4）

| 指标 | 计算逻辑 | 数据来源 | 关键字段 | 状态 |
|------|----------|----------|----------|------|
| 客单价 | 净收入 ÷ 订单数 | DWS `dws_sales_daily` | `aov` / `net_revenue`,`order_cnt` | 已有（渠道/总览可算） |

| SKU 退货贡献 | 退货额占比 TOP | `dwd_sales_wide` | 退货诊断路径 | 已有（方法论） |

### 1.5 围栏指标（单独列出）

| 围栏指标 | 为何设为围栏 | 优化北极星时的底线 |
|----------|--------------|--------------------|
| 退货率 | 冲收入易抬退货，伤害毛利与口碑 | 不得为冲销量牺牲退货率 |
| 经营净现比 | 利润可做账，现金不能假 | 净利率升而净现比崩 → 违规优化 |
| 库存周转天数 | 压货可抬短期收入 | 周转恶化视为围栏击穿 |

## 2. 警戒线规则表

| 指标 | 正常 | 关注（预警） | 异常（诊断） | 判断依据 |
|------|------|--------------|--------------|----------|
| 净利率 | ≥ 基准±1pp 内 | 环比 ↓1–2pp 或 同比 ↓1–2pp | 环比 ↓>2pp 或绝对值 <5% | 环比/同比/绝对值 |
| 毛利率 | ≥35%（作品集演示阈值） | 同比 ↓1–2pp | 同比 ↓>2pp 或 <32% | 同比/绝对值 |
| 净收入 | 同比 ≥0 | 环比 ↓3–8% | 环比 ↓>8% 或 同比 ↓>10% | 环比/同比 |
| 退货率（围栏） | ≤12% | 12–15% 或 环比 ↑1–3pp | >15% 或 环比 ↑>3pp | 绝对值/环比 |
| 库存周转天数（围栏） | ≤ 品类基准 | 超基准 10–20% | 超基准 >20% 或连续 2 月恶化 | 绝对值/趋势 |
| 净现比（围栏） | ≥0.8 | 0.5–0.8 | <0.5 | 绝对值 |
| ROE | ≥ 同行/历史中位 | 环比 ↓1–2pp | 环比 ↓>2pp | 环比 |
| ROAS | ≥2 | 1–2 | <1 | 绝对值 |

## 3. 指标 ↔ 看板映射

| 指标 | 看板 | 展示位置 |
|------|------|----------|
| 净利率 / ROE | 杜邦分析、利润质量 | KPI / 杜邦树 |
| 净收入、毛利率、GMV、退货率、周转 | **经营总览** | KPI 卡片（总览标注核心/围栏） |

| 库存周转 | 库存分析 | KPI + 表 |

| 现金流/净现比 | 现金流、利润质量 | KPI |

## 4. 指标 ↔ 数仓映射

| 指标 | 计算逻辑 | 层级对象 | 关键字段 |
|------|----------|----------|----------|
| 净收入/毛利/退货 | 日/月汇总 | DWS `dws_sales_daily`/`monthly` → ADS `v_overview` | `net_revenue`,`gross_profit`,`return_rate_pct` |
| ROE 拆解 | 杜邦三因子 | ADS `v_dupont` | `roe_pct`,`net_margin_pct`,`asset_turnover`,`equity_multiplier` |
| 费用 | 月费用汇总 | DWS `dws_expense_monthly` | `expense_amt`,`expense_rate_pct` |
| 库存周转 | 库存÷销货成本 | DWS `dws_inventory_daily` | `turnover_days`,`inventory_amt` |
| 现金流 | 经营/投资/筹资 | DWS `dws_cashflow_monthly` | `cfo`,`profit_to_cash_ratio` |
| 明细下钻 | 订单宽表 | DWD `dwd_sales_wide` | 品牌/渠道/品类/SKU |

看板 SQL **只读 DWS/ADS**，不下钻时不直连 ODS。

## 5. 缺失与补充（优先级）

| 优先级 | 缺失项 | 建议 |
|--------|--------|------|
| P0 | 总览 KPI 未标北极星/围栏 | ✅ 本轮：KPI `role` 标签 + 页头说明 |
| P1 | 总览无「净利率」卡片 | 在 `v_overview`/API 增加净利率 KPI（微调，不新开看板） |
| P1 | 警戒线未产品化 | 配置表或 JSON 阈值，总览变黄/红（二期） |
| P2 | 先导「新品销售占比」 | DWS 增 `new_product_flag` 汇总字段 |
| P3 | 统一告警中心页 | 非必须；健康灯可挂总览 |

## 6. 总览页标注约定

- **北极星**：净利率（完整看杜邦；总览用说明条指向）  
- **围栏**：退货率、库存周转天数（KPI 角标「围栏」）  
- **核心**：净收入、毛利率
