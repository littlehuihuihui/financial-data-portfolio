⚙️ 制造业数据仓库架构

ODS → DIM → DWD → DWS → ADS 五层数仓（database/）；宽表优先、主题聚合，14 个 Web 看板与 Tableau SQL 直接消费 DWS/ADS。作品集版 · 宽表 + DWS + 14 看板 API

分层是什么？每一层存什么粒度的数据？

ODS · 操作数据层
颗粒度：业务系统原始单据/记录级（一行一条业务事实）。贴近 MES/ERP/WMS 的原始落地，8 张表：生产工单（ods_production_order，一行一工单）、质检记录（一行一检验批次）、物料库存快照（一行一物料一日）、设备状态、工时记录等。保留源系统主键，不做复杂聚合。
DIM · 维度层
颗粒度：描述性主数据（一行一个维度实体）。5 张表：产品（dim_product，一行一 SKU）、产线（一行一产线）、供应商（一行一供应商）、物料（一行一物料编码）、日期（一行一天）。用于统一口径与名称映射。
DWD · 明细宽表层
颗粒度：清洗后的明细宽表（一行一条业务事实 + 冗余维度）。3 张宽表：生产宽表（一行一工单，冗余产线/产品/工时/成本）、质量宽表（一行一质检批次）、供应链宽表（一行一采购/库存事务）。查询时最多关联 1–2 张表。
DWS · 汇总数据层
颗粒度：按时间 × 主题预聚合（一行一个汇总单元）。5 张表：日生产汇总（一行 = 某日×某产线，产量/产能利用率/工时）、日质量汇总（良品率/不良率）、日供应链汇总（采购额/周转天数）、日设备汇总（OEE/故障率）、月成本汇总（一行 = 某月×某工厂，总成本/单位成本/成本结构）。
ADS · 应用数据层
颗粒度：面向看板/API 的主题视图与查询（封装指标口径，可跨 DWS 关联）。14 个主题看板 API（含报废返工/工序良率/停机/BOM/供应商评分等扩展），一行对应看板图表所需的一个分析切片（如日趋势一点、产线对比一行）。

记忆口诀：ODS 存原始 → DIM 定口径 → DWD 宽表洗 → DWS 先算好 → ADS 给业务用。

数据源与数据库选型

制造业同时对接 ERP（工单/BOM/成本） 与 MES/SCADA（报工/设备实时）；离线 Hive 承载日结，时序/实时库服务产线监控，ClickHouse/Hologres 做 OEE 与质量多维分析。规范见制造业 docs/03_技术栈选型说明.md。

数据来源（5 大业务域）

生产域（工单/产线/工时）· 质量域（质检/不良/返工）· 供应链域（采购/库存/供应商）· 设备域（OEE/故障/维护）· 成本域（材料/人工/制造费用）。样例灌入见 database/seed_manufacturing_data.py。
