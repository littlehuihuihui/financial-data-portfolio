# 制造业 · 数据监控指标体系

> 五层监控：北极星 → 核心 → 先导 → 诊断 → 警戒线  
> 与看板 / 数仓对齐；**不新增主题看板**。  
> 状态：文档 v1.0 · 对齐作品集 manufacturing v1.8

## 0. 角色定义（本页必读）

| 标签 | 含义 | 本行业选定 |
|------|------|------------|
| **北极星** | 唯一主优化目标 | **CMEI** = FPY×40% + OEE×35% + OTD×25% |
| **围栏指标** | 冲 CMEI 时不能恶化的底线 | **良品率/FPY**、**单位成本**、**来料不良（PPM）** |
| 核心指标 | 周/月必看 | 产量、FPY、OEE、OTD（准时交付） |
| 先导指标 | 更早预判 | WIP、设备故障率/停机、来料不良率、换型时长 |
| 诊断指标 | 异常下钻 | 产线良品率、班组产量、不良类型占比、设备三因子、供应商 OTD |
| 警戒线 | 阈值（多板已有 `alert_level`） | 见 §2 |

**说明：** 单追 OEE 或产量而牺牲 FPY/成本，视为围栏击穿；CMEI 已含 FPY/OEE/OTD，围栏再锁成本与来料质量。

### 1.5 围栏指标

| 围栏 | 为何 | 底线 |
|------|------|------|
| 良品率 / FPY | 冲产能易出废品 | FPY 掉而产量升 → 击穿 |
| 单位成本 | 加班/赶工抬成本 | 成本失控不认 CMEI「假好」 |
| 来料不良 PPM | 供应质量输入 | 来料恶化必拖 FPY |

## 2. 警戒线规则表

| 指标 | 正常 | 关注 | 异常 | 依据 |
|------|------|------|------|------|
| CMEI | ≥ 目标（如 90） | 目标-3～目标 | < 目标-3 或环比 ↓>2 | 绝对值/环比 |
| 良品率（围栏） | ≥95% | 92–95% | <92% 或 <90% 严重 | 绝对值（与看板 alert 对齐） |
| OEE | ≥80% | 75–80% | <75% | 绝对值 |
| OTD | ≥95% | 90–95% | <90% | 绝对值 |
| 单位成本（围栏） | 环比 ≤+3% | +3–5% | +>5% | 环比 |
| WIP | ≤ 警戒件数 | 超 10–20% | 超 >20% | 绝对值 |
| 来料 PPM（围栏） | ≤ 协议 | 超 10–30% | 超 >30% | 绝对值 |
| 产能利用率 | 70–95% | <70% 或 >98% | 持续偏离 | 绝对值 |

与现有看板 `alert_level`（严重/关注/预警/正常）一致处，以看板规则为准。
