# 制造业 · 数据分析方法论（完整版）

与零售财务、互联网行业框架统一，面向离散/流程制造通用场景，严格遵循工业工程与精益生产标准。

**业务主线：** 原材料采购 → 生产加工 → 质量检验 → 成品入库 → 交付客户  
**核心目标：** 保质量、降成本、提效率、稳交付  
**北极星指标：** CMEI（综合制造效能指数）= FPY×40% + OEE×35% + OTD×25%  
> **状态：最小可用** — 已落地 ADS 视图 `v_cmei_daily`（由加权 FPY/OEE/OTD 合成）。**SPC 控制图 / `dws_spc_analysis` 仍为规划中**，方法论与看板勿宣称已有独立 SPC 事实表。

## 第一层 · 描述性分析（What happened? 发生了什么）

> 回答：生产现场现在是什么状态？指标是多少？和目标比差多少？

| 分析场景 | 核心指标 | 关联看板 |
|---------|---------|---------|
| 生产总览 | CMEI、日产量、计划达成率、在制工单 | 生产监控看板 |
| 质量概况 | FPY一次通过率、不良率、PPM、返工率、报废率 | 质量分析看板 |
| 设备状态 | OEE、可用率、性能率、质量率、MTBF/MTTR | 设备OEE看板 |
| 生产执行 | 工单完成率、人均产出、工序效率、班组绩效 | 生产执行看板 |
| 供应链物料 | 库存金额、周转天数、到货准时率、缺料数 | 供应链看板 |
| 成本概况 | 单位制造成本、材料成本占比、人工/制造费用 | 成本分析 |
| 人员效率 | 人均小时产出、出勤率、加班时长 | 人工效率 |
| 能源消耗 | 单位产品能耗、峰谷电占比、水电气消耗 | 能源管理 |

## 第二层 · 诊断性分析（Why it happened? 为什么发生）

> 回答：指标异常的原因是什么？哪个环节出了问题？

| 异常场景 | 下钻维度 | 诊断方法 |
|---------|---------|---------|
| FPY良率下降 | 产线→产品→工序→不良类型→班次→人员→批次 | 柏拉图分析、分层法 |
| OEE效率低 | 设备→停机原因→换型时间→小停机→速度损失 | OEE三因子分解 |
| 计划达成率低 | 工单→工序→瓶颈→缺料→设备故障→人员 | 瓶颈分析、关键路径法 |
| 单位成本上升 | 材料→人工→制造费用→废品损失→能耗 | 成本卷积、差异分析 |
| 供应商准时率低 | 供应商→物料→采购周期→物流→质检 | 供应商分级、交期分析 |
| 设备故障高 | 设备→故障类型→保养记录→使用年限→备件 | 故障树FTA分析 |
| 在制品WIP高 | 工序→产线→工单→瓶颈工序→批量大小 | 利特尔法则、价值流 |
| 交付延期 | 订单→产品→工序→缺料→质量返工→设备 | 订单全链路追踪 |

## 第三层 · 预测性分析（What will happen? 会发生什么）

> 回答：未来会怎么样？有没有风险？需要提前准备什么？

| 预测场景 | 预测方法 | 业务价值 |
|---------|---------|---------|
| 产量/产能预测 | 时间序列、订单BOM展开、产能负荷 | 提前排产、人力安排 |
| 物料需求预测 | MRP运算、安全库存模型、提前期 | 避免缺料停线、减少库存积压 |
| 设备故障预测 | 振动/温度传感器数据、故障间隔分布 | 预测性维护、减少非计划停机 |
| 质量风险预测 | 过程参数SPC控制图、批次追溯 | 提前预警、避免批量不良 |
| 订单交付预测 | 工序进度、在制状态、瓶颈产能 | 交期承诺、客户沟通 |
| 人力需求预测 | 生产计划、标准工时、人员效率 | 排班优化、加班控制 |
| 成本预测 | BOM成本、材料价格趋势、费用预算 | 成本管控、报价支持 |

## 第四层 · 处方性分析（What should we do? 应该怎么做）

> 回答：针对问题应该采取什么措施？不同方案的效果是什么？

| 问题场景 | 优化方案 | 预期效果 |
|---------|---------|---------|
| 设备OEE低 | TPM全员生产维护、SMED快速换模、预测性维护 | OEE提升5-15% |
| 良率低 | SOP标准化、防错Poka-Yoke、SPC过程控制、人员培训 | FPY提升2-5% |
| 产能瓶颈 | 瓶颈工序改善、增加班次、工艺优化、自动化改造 | 产能提升10-30% |
| 库存高 | JIT准时生产、拉动式生产、VMI供应商管理库存 | 库存周转提升20-40% |
| 换型时间长 | SMED快速换模、标准化作业、并行作业 | 换型时间减少30-60% |
| 交付延期 | 关键路径排程、缓冲设置、异常快速响应 | OTD提升5-10% |
| 成本高 | 价值工程VE、材料替代、能耗优化、减少浪费 | 单位成本降低3-8% |

## 第五层 · 根因分析（Root Cause 根本原因是什么）

> 回答：问题的根本原因是什么？不是表面现象，是真因。

| 根因方法 | 适用场景 | 制造业应用示例 |
|---------|---------|--------------|
| **5Why分析法** | 单一明确问题 | 为什么停线？→设备坏了→为什么坏？→轴承磨损→为什么磨损？→没润滑→为什么没润滑？→润滑泵堵了→为什么堵？→油里有杂质→根本原因：滤油器没定期更换 |
| **鱼骨图（5M1E）** | 复杂质量问题 | 人（Man）：新员工没培训；机（Machine）：设备精度下降；料（Material）：原料批次不合格；法（Method）：SOP参数不对；环（Environment）：温湿度不达标；测（Measurement）：量具不准 |
| **故障树分析FTA** | 设备故障/安全事故 | 顶事件：设备停机→中间事件：电气故障/机械故障/人为误操作→底事件：保险丝断/轴承断/操作失误 |
| **5W2H** | 问题明确描述 | What/Why/When/Where/Who/How/How much，完整还原问题现场 |
| **8D问题解决法** | 客户投诉/重大质量问题 | 组建团队→描述问题→临时围堵→根因分析→永久措施→验证效果→预防再发→团队祝贺 |
| **分层法** | 多因素混杂问题 | 按班次/人员/设备/材料/时间分层，找到差异最大的维度 |

## 第六层 · 闭环优化（How to improve continuously? 如何持续改进）

> 回答：如何形成PDCA循环，持续改善，避免问题再发？

| 闭环环节 | 制造业落地方法 |
|---------|--------------|
| **Plan 计划** | 改善项目立项、目标设定（SMART）、方案制定、资源准备 |
| **Do 执行** | 小范围试点、标准化作业、人员培训、数据记录 |
| **Check 检查** | 改善前后指标对比、效果验证、是否达到目标、有没有副作用 |
| **Act 处理** | 有效措施标准化到SOP、更新制度、横向展开到其他产线、遗留问题进入下一个PDCA |
| **持续改善** | Kaizen提案制度、QC小组活动、每日早会复盘、安灯异常快速响应、月度经营分析会 |
| **绩效闭环** | 指标分解到班组/个人、绩效挂钩、定期回顾、奖惩机制 |

## 🏭 制造业专属分析工具箱

| 分析方法 | 核心思想 | 应用场景 |
|---------|---------|---------|
| **OEE设备综合效率** | 可用率×性能率×质量率，量化设备损失 | 设备管理、产能提升 |
| **柏拉图（80/20）** | 80%的问题来自20%的原因 | 不良分析、故障分析、成本分析 |
| **SPC统计过程控制** | 控制图监控过程波动，区分普通/特殊原因 | 质量过程管控、异常预警 |
| **价值流图VSM** | 从原材料到成品的全流程价值/浪费分析 | 精益改善、流程优化 |
| **SMED快速换模** | 区分内换型/外换型，把内换型转外换型 | 减少换型时间、小批量生产 |
| **TPM全员生产维护** | 自主保养、计划保养、个别改善、初期管理 | 设备零故障、零不良 |
| **安灯Andon系统** | 异常立即呼叫、快速响应、停线解决 | 现场异常管理、质量追溯 |
| **BOM成本卷积** | 从原材料→半成品→成品逐层卷积成本 | 成本核算、报价、差异分析 |
| **瓶颈分析TOC** | 系统产出由瓶颈决定，聚焦瓶颈改善 | 产能提升、排产优化 |
| **标准工时** | 工序标准时间、宽放率、人员定编 | 效率核算、排班、成本核算 |
| **RCA根因纠正预防** | CAPA纠正预防措施，避免问题再发 | 质量问题闭环、客诉处理 |
| **防错Poka-Yoke** | 从设计上避免错误，不靠人注意 | 质量零缺陷、减少人为错误 |

## 🏗️ 数仓模型设计

### 数仓分层架构
```
ADS 应用层 → 5大主题看板视图（生产/质量/OEE/执行/供应链）
 ↑
DWS 汇总层 → 日/班/月汇总表（生产日汇总、质量日汇总、OEE日汇总）
 ↑
DWD 明细层 → 事实表（生产事实、质量事实、设备事实、物料事实）
 ↑
DIM 维度层 → 维度表（日期、产线、产品、设备、供应商、人员、工序、班次）
 ↑
ODS 贴源层 → 原始数据（ERP/MES/SCADA/WMS/QMS）
```

### 核心事实表（雪花模型）
1. **dwd_production_fact**：生产工单事实表（工单粒度）
2. **dwd_operation_fact**：工序报工事实表（工序报工粒度）
3. **dwd_quality_fact**：质量检验事实表（检验单粒度）
4. **dwd_device_fact**：设备运行事实表（分钟/小时粒度）
5. **dwd_material_fact**：物料出入库事实表（出入库单粒度）

### 核心维度表
1. **dim_date**：日期维度
2. **dim_production_line**：产线维度（雪花层级：工厂→车间→产线）
3. **dim_product**：产品维度（雪花层级：品类→产品）
4. **dim_device**：设备维度（雪花层级：设备类型→设备）
5. **dim_supplier**：供应商维度（雪花层级：供应商分类→供应商）
6. **dim_employee**：人员维度（雪花层级：部门→班组→员工）
7. **dim_operation**：工序维度（雪花层级：工艺路线→工序）
8. **dim_shift**：班次维度

### ER图关系（雪花模型，层级≤3层）
```
                    ┌─────────────┐
                    │  dim_date   │ 日期维度
                    └──────┬──────┘
                           │
┌──────────────────┐    ┌──┴──────────────┐    ┌──────────────────┐
│ dim_production   │────│dwd_production   │────│    dim_product   │
│ line (工厂→车间→ │    │   _fact          │    │ (品类→产品)      │
│ 产线，3层雪花)   │    └──────────────────┘    └──────────────────┘
└──────────────────┘              │
                                  │
                    ┌─────────────┴─────────────┐
                    │      dim_device           │
                    │ (设备类型→设备，2层雪花)   │
                    └───────────────────────────┘
                                  │
                    ┌─────────────┴─────────────┐
```

## 🔗 数据血缘关系

### 核心指标血缘（CMEI综合制造效能指数为例）
```
业务源：MES工单 + 质检记录 + 设备日志
    ↓
ODS层：ods_production_order / ods_quality_inspection / ods_device_log
    ↓ 清洗、去重、格式统一
DWD层：dwd_production_fact / dwd_quality_fact / dwd_device_fact
    ↓ 按天+产线汇总计算FPY/OEE
DWS层：dws_production_daily / dws_quality_daily / dws_oee_daily
    ↓ 按权重计算CMEI = FPY×40% + OEE×35% + OTD×25%
ADS层：ads_production_monitor（生产监控看板视图）
    ↓
看板：生产监控看板 / 总览大屏
```

### 核心指标血缘（OEE设备综合效率为例）
```
业务源：SCADA设备状态日志 + MES报工数据
    ↓
ODS层：ods_device_log（设备状态原始日志）
    ↓ 清洗、状态识别、停机分类
DWD层：dwd_device_fact（设备运行明细事实表）
    ↓ 按天+设备汇总：可用率、性能率、质量率
DWS层：dws_oee_daily（设备OEE日汇总表）
    ↓ OEE = 可用率 × 性能率 × 质量率
ADS层：ads_oee_dashboard（OEE看板视图）
    ↓
看板：设备OEE看板
```

### 数据血缘管理原则
1. **全链路追踪**：每个指标都能追溯到原始源系统和源表
2. **影响分析**：修改上游表时，能快速定位影响的下游指标和看板
3. **口径一致性**：同一指标（如OEE/FPY）在不同看板计算口径必须一致
4. **元数据记录**：每张表、每个字段都有中文注释、业务含义、数据来源
